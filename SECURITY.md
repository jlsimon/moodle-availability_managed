# Security policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please do not disclose potential vulnerabilities in a public issue. Report
them privately through
[GitHub's security advisory form](https://github.com/jlsimon/moodle-availability_managed/security/advisories/new).

Include the affected version, Moodle version, reproduction steps, and the
impact you observed. Reports will be acknowledged as soon as practical and
coordinated disclosure will be arranged after a fix is available.
